# ACK 원고 v2.5 반영용 방어 실험 보충안

상태: 팀 검토용 문안. 기존 제출 원고/claim snapshot을 변경하지 않는다.

## 방법 문단

기존 선박 이미지 분류기의 입력에 고정 3×3 가우시안 평활화 커널을 적용하여
전처리 방어의 효과를 탐색하였다. 모델 가중치를 재학습하지 않았으며 기존 평가
표본, 리사이즈 및 정규화 경로를 유지하였다. 원래 분류기에 대해 생성한 FGSM을
방어 입력으로 전달하는 조건과, 전처리 및 분류기를 포함한 전체 경로의 기울기를
이용하여 생성한 방어 인지 FGSM 조건을 구분하였다. 공격 예산은 전처리 전 입력에
대해 측정하였다. 커널은 고정하였고 본 테스트셋 결과에 따른 파라미터 탐색은 하지 않았다.

정확도는 전체 테스트 표본을 분모로 계산하였다. ASR은 각 평가 경로가 정상
입력에서 올바르게 분류한 표본을 분모로 사용하였고, 방어 전후 공통 정답 표본의
공격 성공률도 별도로 집계하였다. 따라서 방어 유무에 따른 ASR 분모의 차이를
명시하고, 방어로 인한 정상 정답 손실과 원래 오답의 회복을 함께 분석하였다.

## 해석 문단

본 실험에서 고정 가우시안 전처리는 원래 분류기를 대상으로 생성한 FGSM 입력에
대해 정확도를 개선하였다. 그러나 방어 인지 FGSM 조건에서는 이러한 효과가
유지되지 않았다. 이는 전달 공격만으로 방어 효과를 평가할 경우 평가 결과가
낙관적으로 나타날 수 있음을 보여준다. 또한 정상 입력에 대한 영향은 모델별로
달랐으므로 해당 전처리를 일반적인 성능 개선 또는 견고성 보장으로 해석할 수 없다.

## 연구 범위와 제출 전 결정

- 본 결과는 별도 experimental 탐색 결과다. 기존 FGSM provisional 상태와 공식 채택 조건을 바꾸지 않는다.
- 한 단계 FGSM 평가이며 반복 공격·물리적 공격·센서 융합·자율항해 의사결정의 안전성을 검증하지 않았다.
- 원본 배열이 없어 업로드 후 독립 검증은 CSV/JSON·해시·예측 기록 대조 범위다. 실제 추론은 사용자 Windows 실행이다.
- 지면이 부족하면 공격/근거 감사 본문을 유지하고 본 내용은 부록 또는 후속 연구로 분리한다.
- 최종 본문 포함 여부, 저자/소속, 63장 사람 검토 과정, 데이터 사용 근거는 팀 확인이 필요하다.
- 기존 논문 수치 스냅샷에 방어 수치를 추가할 때는 이 별도 CSV 근거와 감사 결과를 연결한다.
