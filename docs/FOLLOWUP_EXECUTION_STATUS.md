### 결과 보존과 표 생성

아래 명령은 실행 중인 보고서를 한 번 읽고, 그 시점에 완료된 CSV만 바이트 그대로 복사한다. 복사본을 감사한 뒤 새 폴더를 게시한다. 기존 폴더 덮어쓰기와 손상 결과 보존은 거부한다. `SUMMARY.md`는 부분 범위·ASR 분모를 표시하며 Clean/필터 Clean의 변화는 공격 성공률로 표시하지 않는다.

```bash
python -m verification.followup_snapshot <실행결과폴더> <새체크포인트폴더>
```

프로세스와 저장 공간이 유지되는 동안 계산은 진행될 수 있지만, 이 문서가 무인 실행의 지속이나 자동 Git 게시를 보증하지는 않는다. 후속 확인 때 로그·최종 상태와 전체 CSV를 다시 확인해야 한다.

### 실행 프로세스 종료 확인과 복구

2026-10-02 00:08 KST 점검에서 기존 두 실행 세션은 더 이상 존재하지 않았고 해당 평가 프로세스도 찾지 못했다. 마지막 로그 갱신은 BIM 10월 1일 23:50:47 KST, PGD 23:50:26 KST였다. 종료 원인은 확인하지 못했다. 따라서 위 캡처의 `RUNNING`은 파일에 남은 과거 상태이지 실제 생존 증거가 아니다. 기존 run.json/CSV는 변경하지 않았다.

`--resume-from`은 기존 조건을 새 실행 폴더로 복사하고 부모 보고서 SHA-256·부모 코드 버전·계승 조건 수를 명시한다. 동일한 공격 설정·입력 해시·기록된 실행 환경을 요구하고, 평가 실행기/복구 코드 외 공격·추론 소스가 달라지면 거부한다. 미완료 조건은 첫 배치부터 다시 계산한다. 서로 다른 시점의 실행을 결합한 결과이며 새로운 독립 검증이라고 주장하지 않는다. 실행 보고서는 이제 임시 파일 작성 후 교체하여 갱신 도중 잘린 JSON을 줄인다.

복구 시에도 모델·이미지 전체 해시를 기존 검사로 확인한다. 장기 실행 완료는 프로세스 존재만으로 판단하지 않고 최종 보고서와 16조건 CSV 감사로 확인한다.
