# 설계·코드 감사 후속 조치

Jules/Claude 보고서는 검토 입력이며 독립적인 GPU 추론 승인으로 취급하지 않는다.

- 원시 CSV/run.json을 보존하고 공개 BIM 집계에서 clean/defended_clean ASR을 비웠다. filter_harm_rate는 clean 정답 중 필터 후 오답, filter_recovery_rate는 clean 오답 중 필터 후 정답, net_clean_accuracy_change는 전체 표본 기준 순변화다. 공통 정답 집합 ASR을 추가했다.
- adaptive 방어를 주 지표, transfer를 비적응 참고치로 표시한다. 전달·적응 모두 예측은 f(D(x_adv))이고 공격 대상만 f 대 f∘D로 다르다.
- MobileNet 12.42%는 FGSM 무방어 ε=.01 결과다. BIM 0%와 공격을 섞지 않는다. BIM10/PGD20×5 차이의 원인을 계산 예산 하나로 귀속하지 않는다.
- JSMA 예산은 scalar_channel_feature 단위다. 표적/비표적 성공률 및 종료 분포는 저장 행 기반으로 후속 집계하며, 저장되지 않은 L2는 복원했다고 주장하지 않는다.
- 새 복구 실행은 명시적 SHA를 입력한다. 통합 감사는 PGD/JSMA/학습/평가의 유효한 동일 source_commit을 요구한다. BIM 부모는 별도 출처를 보존한다. 같은 SHA 기록도 실행 진위나 깨끗한 작업 트리를 독립 증명하지 않는다.
- 진행 중인 recovery-20261005T165652는 3294dcc를 유지한다. 이번 게시/감사 코드 변경 때문에 실험 셀을 재실행하지 않는다. 완료 후 새 감사기로 저장 산출물을 별도 검사한다.
- 내부적으로 일관되게 위조된 CSV와 요약은 저장 일관성 감사만으로 탐지할 수 없다. 외부 해시 앵커·GPU 로그·독립 추론은 별도 근거다.
- clean-only 대조군, 강한 공격 평가, 근접 중복 검사는 후속 확장이다. 현재 전체 완료/일반적 강건성/외부 승인 주장 없음.

검증: 공개 BIM 16조건 원시 CSV 감사 후 재집계, 관련 회귀검사 12개 통과. 전체 GPU 5단계 완료와 최신 CI는 별도 병합 조건이다.
