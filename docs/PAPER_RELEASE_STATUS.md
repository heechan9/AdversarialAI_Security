## 최종본 작업 순서

1. 완료: v3.5 원본 확보·해시 기록, v4.0 및 v4.5 로컬 검토본 작성. 버전은 계속 0.5 단위로 갱신한다(v4.5 → v5.0).
2. 완료: Clean·FGSM·가우시안·평균 필터 표를 보존 CSV/JSON과 대조하고 ε=0, 0.01, 0.03, 0.05 및 정확도·ASR 분모를 명시했다.
3. 완료: 확정된 실험 범위와 원자료의 provisional·experimental 이력을 구분하고 방어 인지 조건·정상 성능 손실을 반영했다.
4. 유지: 팀 회신은 비고 설명 확인과 선종 판정을 구분한다. 63장 분할 검토를 동일 표본의 독립 이중 검토로 쓰지 않는다.
5. 남음: 멘토 최종 검토, 미확정 저자 학과·학부, ACK2026 공식 양식·지면 및 최종 Word/PDF 일치를 확인한다.
6. 게시 결정 후 확정 원고의 저장소 경로·Release 링크·파일 해시를 기록한다. 실제 게시 전에는 게시 완료로 표시하지 않는다.

MARIS는 설명용 3D 및 저장 결과 재생 공간이다. 실제 제어·실시간 추론·외부 데이터 성능 검증의 근거로 사용하지 않는다.
