## 최종본 작업 순서

1. v3.5 원본을 확보하고 파일명·수정일·SHA-256을 기록한다.
2. Clean·FGSM·가우시안·평균 필터 표를 보존 CSV/JSON과 대조한다. ε=0, 0.01, 0.03, 0.05와 정확도·ASR 분모를 명시한다.
3. FGSM provisional, 방어 experimental 상태와 방어 인지 조건·정상 성능 손실을 유지한다.
4. 팀 회신은 비고 설명 확인과 선종 판정을 구분한다. 분할 검토를 동일 표본의 독립 이중 검토로 쓰지 않는다.
5. 저자·순서·소속, 인용 출처, 제출 양식·지면 및 Word/PDF의 일치를 확인한다.
6. 확정된 원고의 저장소 경로·Release 링크·파일 해시를 기록한다. 실제 파일 게시 전에는 게시 완료로 표시하지 않는다.

MARIS는 설명용 3D 및 저장 결과 재생 공간이다. 실제 제어·실시간 추론·외부 데이터 성능 검증의 근거로 사용하지 않는다.
