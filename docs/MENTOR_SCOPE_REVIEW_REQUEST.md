# 논문 범위 멘토 검토 요청

멘토님 안녕하세요. 현재까지 검증된 결과를 반영한 ACK 2026 논문 초안 v1.0을 정리했습니다.

현재 초안은 다음 범위를 본문 핵심으로 제안합니다.

1. CNN·MobileNetV2의 781장 Clean 성능 재현
2. 팀 확정 epsilon `0, 0.01, 0.03, 0.05`의 untargeted FGSM 취약성 평가
3. manifest·모델 SHA-256·표본 CSV 기반 Research Evidence Audit과 Paper Claim Audit
4. 두 모델 공통 고신뢰 오분류 후보 63장에 대한 분할 육안검토를 보조 오류분석으로 포함

BIM·PGD·JSMA·방어기법·VLM/LLM·항로 및 충돌 시뮬레이션은 현재 검증 근거가 부족하므로 후속연구로 분리했습니다.

현재 FGSM 표는 기존 provisional 결과를 논문 구조 검토용으로만 넣었으며, 공식 재실행과 감사가 끝나면 같은 위치의 수치를 교체할 예정입니다.

위와 같이 **Clean + FGSM + 재현성·근거감사**를 핵심 기여로 잡고, 63장 육안검토를 보조 오류분석으로 포함하는 범위가 적절한지 검토 부탁드립니다. 추가로 본문에 반드시 포함하거나 제외해야 할 실험이 있다면 말씀 부탁드립니다.

저자 순서·소속·교신저자·동등기여 표기도 실제 기여를 기준으로 별도 확인 부탁드립니다.
