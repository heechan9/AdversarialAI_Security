## 모바일 GPU 준비

실제 GPU 통합 실행은 미검증입니다. 복구 ZIP 업로드, Google Drive 승인, GPU 런타임 할당이 필요합니다.
고정 소스 커밋과 모델/이미지 해시 검사, CPU 자동 대체 차단, 작업 단위 순차 실행을 사용합니다.
새 배치 크기 8과 GPU 환경은 기존 CPU 실험과 구분합니다. 동일 수치 재현을 주장하지 않습니다.

완료된 epoch의 모델·최적화 상태를 체크포인트로 저장합니다. 같은 RUN과 RESUME=True로 명시적으로 재개하며 미완료 epoch는 다시 계산합니다. 체크포인트는 코드·데이터·설정·파일 해시를 검증합니다. 저장된 결과만으로 완료를 추정하지 않습니다.

## 공유폴더 및 재개 수정

- MyDrive 최상위에서 찾지 못하면 인증된 Drive API로 정확한 ZIP 이름을 검색합니다. 공유폴더 파일도 포함하며 페이지 끝까지 확인합니다.
- 서로 다른 내용의 동명 파일이 있으면 임의 선택하지 않습니다. 다운로드 크기·MD5를 확인한 뒤 사용하며 학습 전 이미지·모델 SHA256 감사도 유지합니다.
- 셀 실행 순서가 잘못되면 WORK NameError 대신 실행할 셀을 안내합니다.
- 학습 체크포인트는 완료된 epoch마다 생성하며 last.keras(최적화 상태 포함), best.keras, 해시 매니페스트를 묶습니다. 불완전한 최신 복사본은 건너뛰고 이전의 온전한 epoch로 복구합니다.
- 미완료 첫 epoch에는 복구 가능한 체크포인트가 없습니다. 이 경우 새 RUN으로 시작합니다. 기존 CPU 중단 작업에는 이 기능을 소급 적용할 수 없습니다.
- epoch 순서는 seed+epoch로 결정합니다. 재개 이력을 기록하며 중단 없는 실행과의 비트 단위 동일성은 보장하지 않습니다.
- Drive 백업에는 실행 로그도 포함합니다. 노트북은 최신 버전을 다시 열어야 수정 사항이 적용됩니다.
- JSMA 블록 탐색의 두 번째 속도 개선을 적용했습니다. 1개 이미지의 단축 실행 비교이며 전체 JSMA 평가 완료를 의미하지 않습니다.
- 실제 Colab GPU 실행은 아직 시작/검증되지 않았습니다.
