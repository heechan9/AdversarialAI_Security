# 업로드 공공데이터 반영 계약 (v1.0)

이 문서는 이 채팅방에 업로드된 두 CSV의 실제 반입·검증 범위와 공식 출처를 고정한다.

## 공식 출처

- 제공기관: **울산항만공사**
- `관제기반_선박운항정보.csv`: [울산항만공사_항만 내 선박 운항정보](https://www.upa.or.kr/opendata/publicDataDetail.do?id=15156628), 데이터 ID `15156628`
- `선박위치정보.csv`: [울산항만공사_항내 선박위치정보](https://www.upa.or.kr/opendata/publicDataDetail.do?id=15156631), 데이터 ID `15156631`
- 제공형태: 국가중점데이터 OpenAPI의 샘플 CSV
- 공식 안내 갱신주기: 일간
- 취득·검증 기준일: 2026-08-28

공식 상세 페이지는 첫 자료를 입항·접안·투묘·양묘·이안·이선·출항 등 울산항 선박 운항 프로세스 정보로, 둘째 자료를 위도·경도·속도 등을 포함한 울산항 항내 선박위치정보로 설명한다. API 활용조건은 공식 포털의 활용신청·이용안내를 우선 적용한다.

| 파일 | 레코드 | SHA-256 | 용도 |
|---|---:|---|---|
| `관제기반_선박운항정보.csv` | 522 | `213c6cf3...580f172` | 입·출항 및 관제 이벤트의 기술통계 |
| `선박위치정보.csv` | 528 | `21c51de4...76d784e` | 위치·운항상태 필드의 품질 및 분포 검증 |

## 확인된 품질·기술통계

- 관제 운항정보 결측 셀 3개, 고유 유효 호출부호 1개
- 선박위치정보 결측 셀 1,565개, 고유 유효 호출부호 357개
- 경도 범위 129.20666667~129.78417833, 위도 범위 35.17913833~35.85421667
- 관제 이벤트: 입항 115, 출항 115, 이안 81, 양묘 65, 접안 65, 이선 61, 투묘 20건
- 선박위치 운항상태: `항해(동력)` 207건, 상태 미기재 203건 등
- 두 파일의 `callsgn` 교집합: **0건**
- 따라서 두 추출본을 선박 단위로 결합하지 않는다.

## 적대적 AI 연구에서 허용되는 사용

- 공공 운항정보의 스키마·결측·범위·무결성 검증
- 향후 VLM/LLM 해양 맥락 또는 안전영향 시뮬레이터의 입력 설계
- 이미지 기반 취약성 평가와 운항 맥락 계층을 분리한 시스템 설계 근거

## 금지되는 주장

- 이 CSV가 781장 선박 이미지의 정답 라벨이라는 주장
- CNN·MobileNetV2 학습 또는 Clean/FGSM 성능에 사용했다는 주장
- 두 파일을 `callsgn`으로 결합했다는 주장
- 아직 실행하지 않은 VLM/LLM 또는 안전 시뮬레이션 성능 주장

기계 판독 가능한 검증 결과는 [`results/public_data/vts_summary.json`](../results/public_data/vts_summary.json)에 고정한다.
