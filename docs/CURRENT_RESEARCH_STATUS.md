## 사용 범위와 채택 상태

현재 사용자 요청에 따라 정리하는 공격 강도는 ε=0, 0.01, 0.03, 0.05이다.
정규화된 [0,1] 이미지의 L∞ 교란 크기이며 전압 단위가 아니다.
untargeted 1-step FGSM, true label, [0,1] clipping, L∞ ≤ ε + 1e-6,
ε=0 대조군과 clean-correct ASR 분모를 유지한다. 미실험 강도는 보간하지 않는다.

이 범위의 기존 FGSM 기록은 provisional, 고정 가우시안 전처리 비교는 experimental이다.
범위 사용과 코드 병합은 공식 결과 승격 또는 멘토 승인 기록을 대신하지 않는다.
`configs/fgsm_official_contract.json`은 별도의 팀 확인·실행 식별정보가 필요한
공식 실행 게이트이므로 이 문서 갱신으로 승인 필드를 채우거나 해제하지 않았다.
