# 2026-10-02 모바일 요청 후속 점검

## 검증한 결과

- BIM: 9/16조건. CNN 필터 2개 × epsilon 4개와 MobileNet Gaussian epsilon=0. 조건별 781행, 해시·정답·섭동·정확도·ASR 재계산 통과.
- PGD: 1/16조건. CNN Gaussian epsilon=0만 완료. 비영 epsilon 완료 결과는 없다.
- 보존 위치: `results/extensions/checkpoints/20261002-mobile/`. 부모 실행 결과의 계승 이력을 보존했다. 새로운 독립 재현 승인이 아니다.
- 원본 run.json의 RUNNING은 마지막 기록 상태다. 실행 세션은 종료됐으며 현재 생존 증거로 사용하지 않는다.
- JSMA는 CNN 무방어 1/781장 결과만 저장됐다. 정상 예측도 오분류인 표본이므로 이 표본의 목표 도달을 정상 정답 표본 기준 ASR 성공 사례로 해석하지 않는다. 전체 평가 미완료다.

## 데이터 감사

`available-data-audit.json`은 확보한 test 781장, valid 689장, train 표본 20장의 원본 SHA-256 및 디코딩 RGB SHA-256 감사다.

- test와 valid 사이의 정확 중복은 0개다.
- valid 내부 정확 중복은 0개다.
- test 내부 정확 중복 그룹은 5개다. 고정된 제출용 테스트셋은 수정하지 않았다. 후속 연구에서는 중복으로 인해 표본 독립성이 제한됨을 명시하고, 고유 이미지 기준 민감도 분석을 별도로 고려해야 한다.
- train 표본 20장에서 2개 중복 그룹(Tug_93/94, Tug_95/97)을 확인했다. 표본과 test/valid 사이의 정확 중복은 없지만, 전체 train의 누출 여부를 의미하지 않는다.
- 유사 이미지 및 동일 선박의 다른 프레임 중복 검사는 미실시다.
- train 전체 확보가 끝나지 않아 실제 적대적 학습은 시작하지 않았다. 원본 폴더를 수정하지 않고, 전체 확보 후 별도의 학습용 사본과 제외 목록을 만들어야 한다.
