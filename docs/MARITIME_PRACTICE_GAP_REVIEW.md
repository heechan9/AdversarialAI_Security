# 해상 영상인식 실무와 현재 공격·방어 평가의 차이

확인일: 2026-09-13. 코드 기준 main `324a535`; 현재 상태 문서 PR #27과 함께 검토한다.
새 데이터 수집·수입, 모델 학습, 공격 추가 또는 사이트 배포는 하지 않았다.

MCAD 소개 페이지는 이번 확인에서 '160건 이상'으로 표시되어, 과거 전달된
'295건 이상'을 최신 총계로 재확인하지 못했다. 현재 사건 수를 정답으로 고정하지 않는다.
공개 열람과 데이터 재배포 허가는 다르므로 원본 사건 목록을 저장소에 커밋하지 않는다.
공급사 자료는 활용 목적의 근거이며 실제 운영 효과·공격 취약성의 독립 증거가 아니다.

| 후속 과제 | 영상 검출·추적, 야간·안개·반사·압축, 시간적 지속성 | 적법한 영상 및 조건 메타데이터, 시퀀스 단위 평가 분할 필요 |

'현재 실험 반영'은 현재 구현과 해당 원칙이 부합한다는 뜻이며, 이번 문헌 확인이
이미 끝난 실험의 사전 설계였다고 소급하여 주장하지 않는다.

## 실무 요구와 측정값의 차이

추가 확인한 [Avikus HiNAS Control 공식 제품 설명](https://www.avikus.ai/products-control)은
영상·AIS 및 IR/radar 센서 융합, 항해 보조와 사람의 감시·수동 개입을 설명한다.
이는 공급사가 설명하는 시스템 구성과 용도이며 저시정 안전성이나 공격 저항성을
독립 검증한 근거가 아니다. 해당 페이지의 절감률·안전성 표현은 우리 논문의 성능 근거로 사용하지 않는다.

아래는 웹 자료를 바탕으로 한 **우리 프로젝트의 분석 및 문서 반영 결정**이다.
공급사가 아래 평가 지표를 의무 기준으로 제시했다는 뜻은 아니다.

| 웹 자료에서 확인한 맥락 | 이번 반영 | 후속 검증 조건 |
|---|---|---|
| Orca AI: RGB·열화상 주변 관찰과 상황인식 지원 | 단일 이미지의 선종 분류와 주변 물체 검출·추적을 구분 | 영상 시퀀스와 검출 정답 확보 후 누락·오경보·추적 지속성 평가 |
| Avikus: 여러 센서와 항해 보조, 사람의 감시·개입 | 분류 오류만으로 항해 실패를 단정하지 않도록 THREAT_MODEL의 연결 단계 구분 | 센서 융합·사람의 대응·제어 결과를 각각 측정하는 별도 시험 |
| Plymouth: 시스템과 생애주기별 위협 검토 | 공격자의 텐서 접근 가정과 실제 현장 접근 가능성을 구분 | 실제 카메라 입력 경로와 권한을 확인한 뒤 별도 위협모델 작성 |
| Adaptive attack 연구: 방어를 고려한 평가 | 기존 전달/adaptive FGSM 및 정상 성능 손실을 함께 설명 | 반복·다중 시작점 공격은 별도 실험계약으로 평가 |
| MCAD: 공개정보 기반 사고 기록 | 이미지 평가에 합치지 않고 사건 배경으로만 분리 | 구조화 접근·라이선스와 사건별 센서/벡터 증거 확인 후 도입 판단 |

따라서 이번 반영 대상은 연구 범위와 평가 해석이다. 상용 장비 연동, 센서 융합,
새 영상 수집 또는 MARIS 기능 추가가 완료된 것으로 기록하지 않는다.

| 실무 질문 | 현재 측정 여부 | 현재 결과로 답할 수 없는 부분 |
|---|---|---|
| 주변 표적을 놓치거나 잘못 경보하는가? | 이미지 하나의 클래스만 평가 | 검출 recall/precision, 시간당 오경보, 거리별 누락 |
| 여러 프레임에서 같은 선박을 추적하는가? | 시간동기 영상 없음 | 추적 단절·ID 전환·오류 지속시간 |
| 저조도·해무·파랑에서도 작동하는가? | 해당 조건을 분리한 평가 없음 | 운영 조건별 견고성, OOD 성능 |
| 경보가 제때 제공되는가? | 운영 지연·처리율 시험 없음 | end-to-end latency, 장애 시 대체 절차 |
| 전처리가 방어하는가? | 전달 및 adaptive 1-step FGSM 비교 있음 | 반복 공격까지 포함한 최악 조건 견고성 |
| 오분류가 위험한 조타로 이어지는가? | 제어·승무원 대응 없음 | 충돌 확률·실제 피해·안전 개선율 |

이 표는 제품 인증 요구사항을 대신하지 않는 연구 격차 분석이다.

## 공격·방어 평가에서 유지할 기준

- 정확도는 전체 표본, ASR은 해당 파이프라인의 clean-correct 표본을 분모로 한다.
  두 모델 및 방어 전후의 분모가 다르면 성공 수/분모를 함께 보고한다.
- 고정 전처리의 정상 성능 손실과 공격 조건별 성능을 동시에 공개한다.
  전달 공격의 개선만으로 방어를 평가하지 않는다.
- 현재 adaptive FGSM은 미분 가능한 전체 f(D(x))를 통과하지만 단일 단계다.
  PGD 등 반복 공격 및 최악 조건 견고성을 검증했다고 말하지 않는다.
- 이번 결과만으로 gradient masking을 확정하지 않는다. 추가 공격 진단이 필요하다.
- 작은 L∞ 예산은 지각적 비가시성의 증거가 아니다. ε의 픽셀 단위와 정규화 범위를 명시한다.
- 현재 test set 결과로 커널을 고른 뒤 같은 test set을 독립 검증처럼 사용하는 것은 피한다.
  향후 튜닝에는 별도 validation 분할과 고정 test 평가가 필요하다.
- 현재 781장을 독립적인 운항 사건 781건으로 보지 않는다. 유사영상/시퀀스 관계가
  확인되지 않으면 현장 일반화나 유의성 주장을 추가하지 않는다.
- 감사 통과는 기록 일관성의 증거다. 사용 불가한 H5·원본 픽셀·해상 재현을 대신하지 않는다.

## 과장 방지와 사건 분류

| 피할 표현 | 사용할 표현 |
|---|---|
| 실제 자율운항선박 공격에 성공했다 | 정해진 디지털 입력 접근 가정에서 이미지 분류 오류를 유발했다 |
| ASR이 높아 충돌 위험이 높다 | clean-correct 집합의 오분류 전환율이며 사고 위험은 측정하지 않았다 |
| 사람에게 보이지 않는 공격 | 지정된 L∞ 범위의 교란이며 지각적 비가시성은 별도 검증하지 않았다 |
| 가우시안 방어로 선박 AI 보안 확보 | 전달 공격과 방어 인지 공격을 비교해 고정 전처리의 효과와 한계를 측정했다 |
| MCAD로 모델의 실제 위협 대응 검증 | MCAD는 해양 사이버 위협 배경 참고이며 이미지 성능 검증에는 사용하지 않았다 |

AIS 메시지/표시 위치 조작, GNSS 신호 spoofing, 카메라 영상 기만,
항만 IT 랜섬웨어는 별개 범주다. 단순히 'spoofing'이라고 적혔다고
GNSS 전파 공격이나 적대적 AI 사건으로 확정하지 않는다. 센서·공격 경로가
불명확하면 미확인으로 남긴다. 운영 사고로 연결하려면 실제 접근 가능성,
센서 전달 경로, 시간적 지속성, 다른 센서·사람의 대응, 제어 결과의 추가 근거가 필요하다.

## 이번 보완의 검증 범위

THREAT_MODEL 및 Plymouth 문서를 재사용하고 최신 defense 근거와 연결했다.
README의 지각적 비가시성 단정을 완화했다. 코드·원본 수치·체크포인트·계약은 변경하지 않았다.
이 문헌 대조는 수동 출처 검토이며 기존 Paper Claim Audit의 자동 검사 범위가 아니다.
기존 감사 PASS를 외부 문헌 해석이나 상용 제품 인증으로 표현하지 않는다.

NIST 개요의 분류 축에 대응한 우리 실험의 기술은 다음과 같다. 이는 저장소 계약을
해석한 것이며 NIST가 우리 실험을 평가한 것이 아니다.

- 대상과 단계: 고정된 선박 이미지 분류기의 추론 단계 evasion 실험.
- 목표: true label 기준 untargeted 오분류 유발. 학습 데이터 오염·모델 추출은 평가하지 않음.
- 지식: 모델 기울기에 접근하는 white-box 가정. 방어 인지 조건은 전처리까지 포함.
- 능력: 정규화 입력 텐서를 지정된 L∞ 예산에서 직접 변경. 실제 선박 카메라/통신망 접근 가능성을 입증하지 않음.
- 기록: 입력·소스 해시, 표본별 예측과 집계의 사후 대조. 기록 일관성은 실시간 공격 탐지나 접근 통제의 증거가 아님.

CNIL 가이드의 일부 영문 용어 표기는 그대로 복제하지 않고 evasion과 model extraction을
구분한다. 일반적인 비가시성 예시도 우리 표본의 육안 검증 결과로 가져오지 않는다.
NIST 공식 페이지에는 정오표 안내가 있으므로 논문 인용 시 버전과 원문을 다시 확인한다.
SEA.AI의 프랑스어 페이지는 확인했으나 기업 국적·프랑스 연구 연계의 확정 근거로 사용하지 않는다.
새 데이터·실험·인증 주장을 추가하지 않는다.
