**자율운항선박 이미지 분류 모델의 FGSM 취약성 및 재현성 검증**

**FGSM Vulnerability and Reproducibility Evaluation of Ship Image
Classification Models for Autonomous Ships**

저자 후보(확정 전): 최희찬 · 김태희 · 김기호 · 이재혁

스마트해운물류×ICT멘토링 포세이돈 팀

※ 멘토 검토용 v1.0: 저자 순서·소속·교신저자·동등기여 표기는 실제 기여와
멘토 확인 후 확정한다. AI 도구(Jules, Codex, Claude)는 저자로 기재하지
않고 검증·작성 지원 내역만 기여 기록에서 구분한다.

\[멘토님께 범위 확인 요청\] 현재 근거로는 ‘Clean 성능 재현 + 팀 확정
epsilon의 FGSM 취약성 평가 + 연구근거 감사’를 본 논문의 핵심 범위로
제안드립니다. 엄격 육안검토 63장은 오류분석의 보조 근거로 포함하고,
BIM·PGD·JSMA·방어기법·VLM/LLM·항로/충돌 시뮬레이션은 후속연구로 분리하는
방향이 적절한지 확인 부탁드립니다. 또한 현재 표의 FGSM 값은
provisional이므로, 공식 재실행 완료 전 초안 검토에만 사용할지 또는 공식
실행 후 수치를 교체해 제출할지도 결정 부탁드립니다.

요 약 자율운항선박의 시각 인식 모듈은 미세한 입력 교란에 의해 오분류될
수 있으므로 배포 전 공격 강건성 평가가 필요하다. 본 논문은 10개 선박
클래스의 manifest 고정 테스트 이미지 781장을 대상으로 CNN과
MobileNetV2의 정상 성능을 재현하고, 백색상자 비표적 FGSM 공격을 동일한
평가 계약으로 적용하였다. 정상 정확도는 CNN 64.53%(504/781), MobileNetV2
78.49%(613/781)였다. 팀이 확정한 ε={0, 0.01, 0.03, 0.05} 중 현재
provisional ε=0.03 결과에서 공격 후 정확도는 각각 24.33%와 13.19%,
clean-correct 표본 기준 ASR은 각각 62.30%와 83.20%였다. 평가 이미지와
모델의 SHA-256을 대조하고, canonical CSV·JSON·문서 주장을 독립
감사하였다. 두 모델이 동일한 오답을 0.70 이상 confidence로 출력한 63개
후보를 분할 육안검토한 결과는 라벨 정확 55개, 라벨 오류 의심 4개, 판단
보류 4개였다. 따라서 본 결과는 정상 정확도가 높은 모델도 해당 FGSM
조건에서 높은 강건성을 보장하지 않았음을 보여주지만, 공격 수치의 공식
확정과 육안 판정의 일반화에는 추가 검증이 필요하다.

키워드: 자율운항선박, 적대적 예제, FGSM, 선박 이미지 분류, 재현성

**1. 서론**

자율운항선박은 카메라 등 센서 입력을 기반으로 주변 선박과 장애물을
인식한다. 그러나 딥러닝 모델은 사람이 식별하기 어려운 작은 입력 변화에도
예측이 달라지는 적대적 예제에 취약할 수 있다\[1\]. 해양 자율시스템에서도
데이터 변조와 AI 모델 취약성은 운항 안전과 연결되는 보안 문제로 논의되고
있다\[2\].

기존 연구는 공격 성공 여부나 단일 모델의 성능 저하를 보고하는 경우가
많지만, 결과를 다시 계산할 수 있는 평가 분모와 입력·모델 식별 정보가
함께 제공되지 않으면 수치 비교가 어렵다. 특히 공격 성공률(Attack Success
Rate, ASR)은 전체 표본이 아니라 정상 입력에서 맞춘 표본만을 분모로
삼아야 공격으로 인해 새롭게 발생한 오분류를 구분할 수 있다.

본 연구의 기여는 다음과 같다. 첫째, CNN과 MobileNetV2\[3\]의 정상 성능을
동일한 781장 테스트셋에서 재현한다. 둘째, \[0,1\] 입력 범위에서 ε별
FGSM을 적용하고 정확도, 정확도 하락, clean-correct 기준 ASR, Macro F1과
최대 L∞ 교란을 함께 산출한다. 셋째, 데이터 매니페스트·모델 SHA-256·표본
CSV·실행 메타데이터를 연결하고 Research Evidence Audit 및 Paper Claim
Audit으로 결과와 문서의 일관성을 검사한다. 넷째, 정량 규칙으로 추출한
공통 고신뢰 오분류 후보와 사람의 정성 판정을 분리하여 라벨 오류와 모델
실패를 과도하게 단정하지 않는다.

**2. 실험 설계**

**2.1 데이터와 모델**

실험에는 10개 선박 클래스로 구성되고 \`configs/test_manifest.json\`에
순서·레이블·SHA-256이 고정된 테스트 이미지 781장을 사용하였다. 현재
저장소에는 학습·검증 데이터 전체가 없어 split 간 중복 부재를 독립적으로
확정하지 않는다. 비교 모델은 CNN과 MobileNetV2이며 입력 크기는 각각
128×128×3과 224×224×3이다. 평가 파이프라인에서는 두 모델 모두 \[0,1\]
범위의 rescale=1/255를 사용했으나, MobileNetV2 학습 당시 전처리는 학습
코드 미확보로 직접 확인되지 않았다.

정상 평가에서 CNN은 504장을 맞혀 64.53%, MobileNetV2는 613장을 맞혀
78.49%의 정확도를 기록하였다. 이 값은 이후 ASR의 모델별 분모로
사용하였다.

**2.2 FGSM 공격**

FGSM은 손실함수 J의 입력 기울기 부호를 이용하여 식 (1)과 같이 적대적
입력을 생성한다\[1\].

x_adv = clip\_\[0,1\](x + ε·sign(∇x J(θ,x,y))) (1)

본 연구는 true label을 사용하는 untargeted white-box 공격을 적용하였다.
ε={0, 0.01, 0.03, 0.05}는 2026-09-06 팀 결정으로 공식 실행계약에
확정했으며, 생성된 입력을 \[0,1\] 범위로 제한하였다. ε=0은 정상 입력과
동일한지 확인하는 대조조건으로 사용하였다. 모델 가중치는 공격 전후
동일해야 하며, 각 표본의 L∞가 ε를 넘지 않는지 허용오차 10⁻⁶ 범위에서
검사하였다. 계약 확정은 기존 provisional 결과의 공식 승격을 의미하지
않는다.

ASR은 식 (2)와 같이 정상 입력에서 정답이었던 표본 중 공격 후 오답이 된
비율로 정의하였다.

ASR = N(clean correct ∧ adv wrong) / N(clean correct) (2)

**2.3 재현성 통제**

평가 입력 781장의 상대경로·레이블·체크섬을 매니페스트에 기록하고, CNN과
MobileNetV2 모델 파일의 SHA-256을 함께 고정하였다. Clean CSV는
매니페스트의 경로 순서와 실제 레이블에 결합하고, FGSM CSV는 Clean
경로·레이블·예측·clean-correct mask와 파일명 epsilon에 결합한다. 표본
증거에서 classification report, confusion matrix와 모델별 요약을 다시
계산하며, 누락·스키마 변경·NaN/Inf·비정상 boolean·경로 순회·symlink
escape는 fail-closed로 처리한다.

로컬 Windows 검증에서는 실제 이미지 781장의 SHA-256과 매니페스트가 전부
일치했고 CNN 및 MobileNetV2 모델 바이너리 해시도 메타데이터와
일치하였다. 최신 clean-checkout 독립 검증에서는 전체 pytest 86개가
통과하고 4개가 skip되었으며 Research Evidence Audit과 Paper Claim Audit
8/8이 통과했다. 다만 clean checkout에는 원본 이미지와 .h5 파일이
없으므로 이 환경의 PASS는 저장된 근거의 내부 일관성을 뜻하며 모델 추론의
독립 재실행을 뜻하지 않는다.

**2.4 정량 후보 추출과 엄격 육안검토**

두 모델이 동일한 오답 클래스를 예측하고 두 confidence가 모두 canonical
원시값 기준 0.70 이상인 표본을 정량 후보로 추출하였다. 이 규칙으로 얻은
63개 고유 표본을 김태희 31개와 이재혁 32개로 나누어 검토했으며, 이는
동일 표본에 대한 독립 이중검토가 아니다. 검토자는 이미지에서 확인한 선박
특징을 비고에 기록하고 판정을 ‘라벨 정확’, ‘라벨 오류 의심’, ‘판단
보류’로 제한하였다. 분할본과 통합본, UTF-8 BOM·스키마·검토일·비고
고유성·3자리 confidence 반올림을 canonical Clean CSV와 동적으로
대조하였다.

**3. 실험 결과 및 고찰**

|-----------------------|-------|---------------|--------------|---------|
| CNN                   | 0     | 64.53         | 0.00         | 0.00    |
| CNN                   | 0.01  | 41.61         | 22.92        | 35.52   |
| CNN                   | 0.03  | 24.33         | 40.20        | 62.30   |
| CNN                   | 0.05  | 20.23         | 44.30        | 68.85   |
| MobileNetV2           | 0     | 78.49         | 0.00         | 0.00    |
| MobileNetV2           | 0.01  | 12.42         | 66.07        | 84.18   |
| MobileNetV2           | 0.03  | 13.19         | 65.30        | 83.20   |
| MobileNetV2           | 0.05  | 16.13         | 62.36        | 79.45   |

표 1. FGSM provisional 공격 결과(%, Test 781장; epsilon 계약 확정, 공식
재실행 전)

표 1의 수치는 확정된 epsilon 계약과 동일한 기존 provisional 산출물에서
동적으로 재계산한 값이며, 공식 재실행·결과 고정 전까지 공식 성능
주장으로 사용하지 않는다. CNN은 ε가 증가할수록 공격 후 정확도가 41.61%,
24.33%, 20.23%로 감소했고 ASR은 35.52%, 62.30%, 68.85%로 증가하였다.

MobileNetV2는 정상 정확도가 CNN보다 13.96%p 높았지만 ε=0.01에서 공격 후
정확도가 12.42%까지 하락했다. ε=0.03의 provisional ASR은 83.20%로
CNN보다 20.90%p 높았다. 따라서 본 실험조건에서는 정상 정확도 우위가
적대적 강건성 우위로 이어지지 않았다. 이를 모든 공격·환경에 대한 일반
명제로 확대하지 않는다.

MobileNetV2의 provisional ε별 결과는 단조 감소하지 않았다. ε=0.01, 0.03,
0.05에서 공격 후 정확도가 각각 12.42%, 13.19%, 16.13%로 일부 반등했으며
ASR도 감소하였다. 이를 overshoot 또는 특정 원인으로 단정하지 않고, 공식
재실행과 필요시 사전등록된 보조 실험에서 확인할 관찰 사실로만 기록한다.

엄격 육안검토 63개 후보의 판정은 라벨 정확 55개, 라벨 오류 의심 4개,
판단 보류 4개였다. 이는 전체 781장의 라벨 정확도를 추정한 표본이 아니며,
정량 후보 63장 모두가 라벨 정확하다는 결론도 지지하지 않는다. 또한 두
검토자가 31장과 32장을 분할 담당했으므로 독립 이중 교차검증으로 표현하지
않는다. 본 실험은 디지털 입력에 대한 백색상자 FGSM 취약성 평가이며 물리
환경 공격이나 실제 선박 운항 위험을 직접 검증한 결과가 아니다.
울산항만공사 공공 운항데이터는 해양 맥락 참고자료로만 분리하며 이미지
라벨·모델 학습·Clean/FGSM 성능의 근거로 사용하지 않는다.
BIM·PGD·JSMA·방어·VLM/LLM·항로/충돌 시뮬레이션 성능도 현재 결과 범위
밖이다.

**4. 결론**

본 논문은 선박 이미지 분류 모델 두 종의 정상 성능과 FGSM 취약성을
manifest 고정 781장 테스트셋에서 비교하는 재현성 중심 프레임워크를
제시하였다. provisional 결과에서 MobileNetV2는 정상 정확도가 높았지만
ε=0.03에서 공격 후 정확도 13.19%, clean-correct 기준 ASR 83.20%를 보여
해당 조건에서 정상 정확도 우위가 적대적 강건성을 보장하지 않았다.

재현 가능한 비교를 위해 ASR 분모, 입력 범위, 확정 epsilon, L∞ 제한,
이미지·모델 SHA-256과 결과 형식을 고정하고, canonical 근거와 문서 주장을
독립 감사하였다. 정량 후보 추출과 사람의 정성 판정을 분리한 63개
오류분석에서는 라벨 정확 55개, 오류 의심 4개, 판단 보류 4개가
기록되었다. 다음 단계에서는 동일 계약으로 공식 FGSM을 재실행하고 결과
감사·고정 후 표 1을 교체한다. BIM·PGD·JSMA·방어·VLM/LLM 및 실제 운항
안전성은 멘토와 합의한 범위에 따라 후속연구로 분리한다.
