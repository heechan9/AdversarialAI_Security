# 공공 AIS 운항정보 연계 계약

## 1. 공식 출처

- 데이터명: `해양수산부_선박 AIS 동적정보_20220101`
- 제공기관: 해양수산부
- 공공데이터포털 식별자: `15129186`
- 공식 페이지: https://www.data.go.kr/data/15129186/fileData.do
- 등록일/수정일: 2024-06-26 / 2025-06-23
- 제공형태: CSV 및 자동변환 OpenAPI(JSON/XML)
- 이용조건: 무료, 이용허락범위 제한 없음
- 공식 샘플 규모: 55행
- 제공 가능 기간 안내: 2018-09-01~2023-03-04
- 식별정보: MMSI는 특수문자로 대체되어 제공됨

공식 컬럼은 다음 7개다.

| 공식 컬럼 | 본 프로젝트의 해석 |
| --- | --- |
| MMSI | 비식별 선박 묶음 식별자. 원식별자 복원을 시도하지 않음 |
| 수신시간 | 이미지·이벤트와 시간 결합할 때의 후보 키 |
| 경도·위도 | 운항 위치. 공식 안내에 따라 원값을 60,000으로 나눔 |
| SOG | 대지속력 기반 운항 맥락 후보 |
| COG | 대지침로 기반 운항 맥락 후보 |
| HEDING | 데이터 원문 철자를 보존한 선수방향 항목 |

## 2. 현재 구현

`src/adversarial_ai/data/ais_public.py`는 다음만 수행한다.

1. 공식 7개 컬럼과 순서를 검증한다.
2. 수신시간과 수치 필드를 파싱한다.
3. 경도·위도를 60,000으로 나누고 지리 범위를 검사한다.
4. SOG·COG·HEDING의 기본 범위를 검사한다.
5. 향후 VLM·LLM 또는 Safety Simulation에 전달할 JSON-safe 운항 맥락을 생성한다.

테스트의 행 값은 파서 검증용 합성 fixture다. 공공데이터 원본이나 실제 운항 결과가 아니다.

## 3. 프로젝트에서 허용되는 주장

- 공공 AIS 공식 스키마를 조사하고 검증 가능한 로더를 구현했다.
- 위치·속력·침로·선수방향을 별도의 운항 맥락으로 구조화할 수 있다.
- 향후 이미지 표본과 시간·공간 기준으로 결합하여 인식 오류의 안전 영향을 분석할 수 있다.

## 4. 금지되는 주장

현재 단계에서 다음을 주장하지 않는다.

- AIS가 781장 선박 이미지의 정답 라벨이다.
- AIS를 CNN/MobileNet 학습 또는 Clean/FGSM 평가에 사용했다.
- AIS 결합으로 정확도·ASR·충돌위험이 개선되었다.
- 실제 공공데이터 55행을 저장소에서 실행·검증했다.
- 이미지와 AIS가 같은 선박·시간·위치에서 수집되었다.
- API 실시간 연동이 완료되었다.
