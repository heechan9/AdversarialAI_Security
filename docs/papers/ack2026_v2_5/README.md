# ACK 2026 원고 통합 현황 (v3.0 검토본)

기준 연구 근거: main `57b45cacab738762928c61966728c8742f546839`.

기존 FGSM 원고에 클래스별 분석, 가우시안 전처리의 전달/방어 인지 조건, 63장 분할 검토의 방법과 한계를 통합한 제출 준비본을 작성했습니다.

## 반영 범위

- 김기호의 FGSM 산출물 검토와 원고 설명을 참고했습니다. 기록 검토와 독립 모델 추론은 구분합니다.
- 김태희·이재혁의 담당 분할 검토 회신을 반영하되 동일 표본의 독립 이중 검증이라고 표현하지 않습니다.
- 사용자에게 전달된 김태희의 후속 확인에 따르면 추가 회신의 ‘라벨 정확’은 선종 클래스가 아닌 비고 설명의 정확성을 뜻합니다. 해당 회신은 관찰·설명 확인 자료이며, 이재혁의 선종 판정과 합산하지 않습니다.
- 추가 회신의 ‘60장 라벨 정확’ 같은 통합 선종 판정 집계는 사용하지 않습니다. 다른 판정값도 확인 없이 선종 오류나 설명 오류로 재분류하지 않습니다.
- 기존 고정 CSV는 보존하지만, 기록 일관성 감사 통과를 이미지 라벨의 실제 정확성 입증으로 해석하지 않습니다.
- 기존 검토 증거, canonical 라벨·결과, 모델·실험 계약을 변경하지 않습니다.
- FGSM은 provisional, Gaussian 방어는 experimental입니다. 전달 공격에서의 개선만으로 일반적인 방어 성공을 주장하지 않습니다.
- Plymouth는 위협모델 참고, MCAD는 비이미지 사고 배경 후보, MARIS는 저장 결과 탐색 공간입니다.

## 검증과 남은 일

2026-09-16 자료 대조에서 Research Evidence Audit PASSED, 기존 Paper Claim Audit 9/9 PASSED, Gaussian audit PASSED(6248행/8조건/80개 클래스 요약)를 확인했습니다. 기존 논문 감사는 저장소 주장에 대한 검사이며 새 v3.0 전체의 자동 검증을 뜻하지 않습니다. 원본 이미지·H5·공격 배열의 독립 재실행은 수행하지 않았습니다.

사용자에 따르면 팀은 방어의 논문 포함에 동의했습니다. 이는 experimental 결과의 공식 승격이나 멘토의 기술적 승인을 뜻하지 않습니다. 저자·순서·소속 및 필요한 선종 판정의 최종 채택 확인은 남아 있습니다. 논문 PDF·Word 전체와 개인 회신 원본은 이 PR에 포함하지 않습니다. 전체 원고는 최종본 확정 후 공개한다는 사용자 방침을 유지합니다.

v3.0은 태희 회신 의미와 팀의 방어 포함 동의를 반영한 편집본입니다. v2.5의 모든 결과 표는 동일하며, 신규 평균 필터 실험 결과는 포함하지 않습니다.
