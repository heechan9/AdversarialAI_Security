## Verification and scope

Saved CSV/JSONL hashes, manifest order, query bounds, norms and summary metrics passed the saved-evidence audits. The summary is regenerated by `verification/blackbox_series_summary.py`; CI checks it against `summary_20261003.json`. Adapter tests cover query accounting, deterministic seeding, initialization failure and tampered evidence.

These checks are not independent neural-network replay or approval. Results apply to the recorded model hashes, dataset, seeds and query budgets. They do not establish physical maritime safety. Square schedules differ between budgets. SurFree uses a pinned external upstream implementation with bounded initialization and records only actually queried adversarial candidates.
