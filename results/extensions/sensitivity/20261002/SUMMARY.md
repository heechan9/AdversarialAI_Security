## 재계산

```bash
python -m verification.subset_sensitivity results/extensions/checkpoints/20261002-pc/bim results/extensions/sensitivity/20261002/subsets.json /tmp/bim-sensitivity.json
```

`subsets.json`에는 원본 감사와 잠긴 테스트 manifest의 SHA256을 기록했습니다. 결과 계산은 기존 CSV와 manifest·모델 해시·각 조건의 781행 순서·원본 지표 감사에 통과해야 진행됩니다.
