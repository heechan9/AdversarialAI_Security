## 해석 경계

- 전달 공격에서 일부 회복이 관찰되지만 방어 인지 FGSM에는 유지되지 않습니다. CNN 정상 정확도 손실도 있습니다.
- 모델·필터를 테스트 결과에 맞춰 재학습하거나 튜닝하지 않았습니다.
- 단일 단계 FGSM이며 PGD·물리 공격·실제 자율운항 안전성 검증이 아닙니다.
- raw 배열/H5가 없으므로 픽셀·가중치 불변은 PC 실행의 검사 기록이며 이 환경에서 재추론한 결과가 아닙니다.

## 읽기 전용 감사

```bash
python scripts/audit_mean_defense.py
```

ZIP 및 내부 SHA, source 파일(LF/CRLF 동등성), 입력 메타데이터, canonical Clean·원래 FGSM 예측, ε=0, 기록된 L∞, 전체/클래스별 집계를 검사합니다.
