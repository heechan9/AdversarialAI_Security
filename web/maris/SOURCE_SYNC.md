# MARIS 배포 소스 보존

사이트: https://maritime-adversarial-lab.hc24734503.chatgpt.site/

Sites v4의 성공한 배포 소스 `689e83c708816a904d60d91141c1a4381efaa8dc`를 복사했다. 공급자 전용 `.openai/hosting.json`만 제외했으며 나머지 추적 파일 118개를 바이트 그대로 보존한다. 원래 커밋 이력의 저자나 기여를 재작성하지 않는다. 이번 커밋은 소스 동기화 작업이다.

## 범위

설명용 3D + 과거 Clean/FGSM 결과 재생이며 실시간 추론이나 실제 항해 제어가 아니다. 데이터 기준 커밋은 `public/evidence/provenance.json`을 따른다. 최신 Gaussian 방어 실험은 이 배포본에 들어 있지 않다. GitHub 반영은 기존 사이트 재배포나 자동 배포 연결을 뜻하지 않는다.

## 실행 및 검사

Node와 pnpm 버전은 package.json, 의존성은 pnpm-lock.yaml을 따른다. 이 디렉터리에서 잠금 파일을 유지해 의존성을 설치한 뒤 README의 실행 명령을 사용한다. Sites에 재배포할 때는 기존 프로젝트의 소유자 설정을 복원해야 하며 새 사이트를 만들지 않는다.

2026-09-13 소스 동기화 검사:

- 증거 검사: snapshot SHA-256, 비교 이미지 4개 해시, 6개 변조 거부 PASS.
- 조작 검사: 회전·자동 정지·초기화·핀치·카메라 제한·이미지 경계 30조건 PASS (합성 입력).
- 검사 의존성: TypeScript 5.9.3 및 Three.js 0.185.1, Node 24.19.0.
- 전체 앱 설치·빌드·브라우저 및 실제 모바일/GPU 검사는 이번 동기화에서 재실행하지 않았다. 기존 VALIDATION.md는 배포 작업 당시 기록이다.
- 원본 연구 결과·모델·계약은 변경하지 않았다. 웹 내 비교 PNG는 기존 연구 저장소의 동일 Git blob을 재사용한다.
