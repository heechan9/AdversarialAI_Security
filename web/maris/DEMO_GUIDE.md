# MARIS 발표 시연 — 약 80초

확인한 기존 결과를 재생하는 시연이다. 설명용 선박 모형은 실제 실험 이미지나 항해 제어를 재현하지 않는다. 시작 전에 CASE 01, 나란히 비교, 이미지 배율 1.0×, 전체 통계 CNN·전체 선박·ε=0.03을 선택한다.

| 시간 | 조작 | 짧은 설명 |
|---|---|---|
| 0–12초 | 첫 화면에서 선박을 잠깐 드래그하고 시점 초기화 | “같은 선박인데 AI의 판단은 왜 달라질까요? 이 배는 설명용 모형입니다. 실제 검증은 아래 선박 이미지로 했습니다.” |
| 12–32초 | 실제 이미지 비교하기 → CASE 01 · CNN, 나란히 비교 | “정상 이미지에서는 항공모함, 픽셀을 바꾼 공격 이미지에서는 레저선으로 판단했습니다. 저장된 FGSM ε=0.03 결과입니다.” |
| 32–42초 | 비교 이미지 확대 1회, 한쪽을 조금 드래그, 이미지 초기화 | “두 이미지를 같은 위치와 배율로 살펴볼 수 있습니다. 화면 확대는 공격 강도를 바꾸지 않습니다.” |
| 42–55초 | CASE 03 · CNN 선택 | “같은 모델과 공격 강도에서도 이 이미지는 항공모함으로 정답을 유지했습니다. 공격이 항상 성공하는 것은 아닙니다.” |
| 55–72초 | 전체 결과 → CNN·전체 선박에서 ε=0, 이어 ε=0.03 선택 | “한두 장으로 결론을 내리지 않고 781장 전체를 봅니다. 공격 성공률은 원래 맞힌 이미지 중 공격 후 틀린 비율입니다.” |
| 72–82초 | 두 모델의 강도별 그래프를 보여주며 마무리 | “이 결과는 선박 이미지 분류의 예비 실험입니다. 실제 충돌이나 자율운항 제어의 안전성을 검증한 것은 아닙니다.” |

## 발표 중 지킬 경계

- CASE 01과 CASE 03은 모두 CNN·비표적 FGSM·ε=0.03이며 서로 다른 이미지다. 각 이미지의 정상/공격 쌍을 비교한다.
- 모든 시각 사례는 항공모함이다. 다른 선종을 대표한다고 말하지 않는다.
- 공격 실패를 방어 실험 성공이라고 부르지 않는다.
- 모델 출력 점수는 정답일 확률을 보장하지 않는다. 공격 후 점수가 없는 경우 추정하지 않는다.
- 차이 확대 탭은 필요할 때만 보충 설명한다. 기존 PNG에 기록된 이미지별 정규화 표현이며 새 히트맵이나 실제 섭동 배율이 아니다.
- 전체 통계 선택은 위 사례를 변경하지 않는다. 화면의 두 조건 표시를 확인한다.
- 정상 정확도·ASR은 발표 시 화면에서 읽는다. 발표 대본에 별도 정답 수치를 관리하지 않는다.
- 현재 연구 수치는 provisional이며 설명용 모형 움직임과 연동되지 않는다.
