# 웹 연구 맥락 검토 (2026-09-19)

## 반영 범위
기존 연구·데이터 안내 아래에 접힌 두 항목을 추가했다. 기존 실험 수치, 입력 자료, 모델, 3D 동작은 변경하지 않았다.

- 관람자 안내: 조건 확인 → 표본 근거 확인 → 미확인 범위 구분.
- 직무 연결: 요구사항 추적과 시험평가 관점. 군용 장비 개발·인증·운용 실증 성과로 확대하지 않음.
- 기존 HRD/AX 자료에서 검토한 대상별 설명, 판단 이유와 근거, 사람/AI 기여 구분만 일반 관람자 문장으로 적용. 취업 강의 내용을 실험 증거로 사용하지 않음.

## 사용자 제공 방산 자료 검토
쪽 번호는 PDF의 1부터 시작하는 페이지 번호다. 원본 PDF와 강의 도판은 공개 소스에 포함하지 않는다.

이미지 기반 페이지는 렌더링으로 확인했다. 산업 통계·표준 판번호·채용 동향은 이번 웹에 채택하지 않았으며 최신 공식 근거로 검증한 사실처럼 인용하지 않는다.

## 유지할 경계
- 이미지 분류 정확도 ≠ 체계 신뢰도, 가용도, 사고 확률.
- 고정 전처리의 실험 결과 ≠ 적응형/최악 공격 전체에 대한 방어 보장.
- 실험 기록 재생 ≠ 실시간 추론, 3D 설명 공간 ≠ 실해역/군용 시험장.
- 향후 실제 운용 검증은 별도 범위 합의와 근거가 필요하다.
